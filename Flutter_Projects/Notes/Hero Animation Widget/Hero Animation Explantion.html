🎯 Purpose of Hero Animation

A Hero animation makes the same item look like it smoothly travels from one screen to another screen.

Without Hero:

SCREEN 1                         SCREEN 2

┌──────────────┐                ┌──────────────┐
│              │                │              │
│   🖼️         │    CLICK       │              │
│  small       │ ───────────→   │    🖼️        │
│  image       │                │   big image  │
│              │                │              │
└──────────────┘                └──────────────┘

        ❌ Image suddenly disappears
           and new image appears

With Hero:

SCREEN 1                         SCREEN 2

┌──────────────┐                ┌──────────────┐
│              │                │              │
│   🖼️         │                │              │
│  small       │      🖼️        │    🖼️        │
│              │    ↗    ↗      │    BIG       │
│              │  ↗        ↗   │              │
└──────────────┘                └──────────────┘

        ✅ Image smoothly "flies"
           to the second screen

🔑 The most important concept

Hero animation connects two screens.

             HERO
              │
      ┌───────┴───────┐
      ↓               ↓
   Screen A         Screen B
      │               │
      │               │
   Hero(tag)       Hero(tag)
      │               │
      └───────┬───────┘
              ↓
       Smooth animation

The two Hero widgets use the same tag:

dart
Hero(
  tag: 'productImage',
  child: Image.asset(...),
)

On the other screen:

dart
Hero(
  tag: 'productImage',
  child: Image.asset(...),
)

⭐ Same tag = connection

Screen 1                    Screen 2

Hero                        Hero
tag: 'productImage'         tag: 'productImage'
       │                           │
       └───────────┬───────────────┘
                   ↓
             🖼️ MOVES
             smoothly

If tags are different:

Screen 1                    Screen 2

tag: 'image1'                tag: 'image2'

        ❌ No Hero connection

⚠️ When should you use Hero?

You don't need Hero for every screen transition.

Use it when you want to show a clear relationship between an item on the first screen and the same item on the second screen.

Good situations:

🛒 Product → Product Details

👤 Profile photo → Full Profile

🖼️ Thumbnail → Full Image

📷 Small photo → Photo Viewer

💳 Card → Card Details

📱 List item → Item Details

🧩 Hero vs normal navigation

Normal:

Screen A
   │
   │ Navigator.push()
   ▼
Screen B

⚡ Screen changes

Hero:

Screen A
   │
   │ Navigator.push()
   │
   ▼
Hero finds matching tag
   │
   ▼
🖼️ ─────────────→ 🖼️
   smooth transition
   │
   ▼
Screen B

Notice something important:

Hero does NOT replace Navigator.push().

You still navigate normally:

dart
Navigator.push(
  context,
  MaterialPageRoute(
    builder: (context) => DetailScreen(),
  ),
);

Hero simply adds the smooth visual transition to the navigation.

🎯 One-line definition for your notes

Hero Animation is a Flutter animation that smoothly moves a widget from one screen to another by connecting Hero widgets with the same tag.
